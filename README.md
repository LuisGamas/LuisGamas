### 🚀 Sobre mí

> *"Ingeniero de Software apasionado por convertir ideas espontáneas en soluciones funcionales, con experiencia en proyectos personales, privados y de código abierto."*

Soy un **Ingeniero de Software** especializado en desarrollo multiplataforma con **Flutter**, creando interfaces visualmente atractivas y altamente funcionales. Tengo un historial comprobado en la optimización del rendimiento de aplicaciones y en la entrega de soluciones SaaS completas.

- 🧠 **Especialidad:** Flutter, Dart, Java Android, Next.js
- 🛠️ **Arquitectura:** Clean Architecture, SOLID, TDD
- 📱 **Plataformas:** Android, iOS, Web
- 🌍 **Experiencia:** Soluciones SaaS, aplicaciones publicadas, proyectos open source
- 💡 **Filosofía:** *"El código limpio no solo funciona, también se siente bien al usarlo"*
